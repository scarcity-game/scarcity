# pr-assets

Screenshots for pull request descriptions. This branch has no code and shares
no history with `main`; it is never merged and never deployed.

Images live under `<pr number>/` and are linked from the PR description by raw
URL:

    https://github.com/scarcity-game/scarcity/raw/pr-assets/<pr>/<file>.png

How to take and push them: `clients/web/AGENTS.md`, "Screenshots". Never put
anything else here, and never anything private: the repository is public.
