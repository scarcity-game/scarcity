# libs

Shared libraries (Java 25 by default, children of the root `pom.xml`).
Built: `resource-model` (the resource envelope, store, notifications and read API) and `world-model` (typed game state and its JSON).
Planned: `world-engine`, `world-db`, `world-seed` (#103), `distributions` (seeded, self-describing randomness), `mapgen`.

Each library gets its own `AGENTS.md`, `README.md` and an entry in `/modules.yaml`.
